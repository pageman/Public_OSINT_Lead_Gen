# Beta Partner Discovery

## Goal

Capture requirements from 3-5 potential partners before building any external API or white-label product.

## Questions

1. What signal would be useful enough to integrate?
2. How often would you need it refreshed?
3. Would you consume JSON, CSV, or briefing output?
4. What workflow would the signal change inside your operation?
5. What would make this worth paying for?

## Output

- repeated requested fields
- repeated refresh cadence
- repeated workflow use cases
- blockers to adoption
