# Pricing Architecture

## Free

- public fintech pulse
- core signal summary

## Gated

- historical export
- nowcast
- operator briefing deck

## Paid Pilot

- 30-day workflow sprint
- scoped around one queue or corridor

## Later Beta API

- only if repeated buyer demand exists
- only after internal contracts stabilize

## Rule

Do not monetize raw visibility first. Monetize execution and sharper operational usefulness.
