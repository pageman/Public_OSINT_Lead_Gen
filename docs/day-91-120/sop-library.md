# SOP Library

## Included SOPs

- signal refresh
- weekly publish
- lead triage
- pilot intake review
- case queue update

## Signal Refresh SOP

1. Run ingestion refresh.
2. Inspect the persisted contract.
3. Validate that evidence fields still make sense.
4. Publish or defer if signal quality is weak.

## Weekly Publish SOP

1. Review inputs.
2. Draft pulse.
3. Separate observation from forecast.
4. Run editorial QA.
5. Publish and distribute.

## Lead Triage SOP

1. Review score.
2. Check urgency.
3. Route to nurture, briefing, or pilot intake.

## Pilot Intake Review SOP

1. Review pain statement.
2. Confirm narrow scope.
3. Assign next step.

## Case Queue SOP

1. Update status.
2. Update priority.
3. Record next step.
