# Day 61-90 Issue List

## Milestone Goal

Package the execution layer into a paid pilot and make delivery measurable.

## Issues

1. Define the paid pilot offer.
   Deliverable: scope, pricing, SLA, exclusions, and escalation path.

2. Create pilot sales collateral.
   Deliverable: one-page brief, demo deck, and pilot FAQ.

3. Build pilot intake flow.
   Deliverable: structured intake form and qualification fields.

4. Build case triage workflow.
   Deliverable: assignment, status, and priority handling.

5. Build execution dashboard.
   Deliverable: internal view for cases, risk tags, and recommendations.

6. Add audit trail.
   Deliverable: event logging for interventions and outputs.

7. Wire Slack alerts.
   Deliverable: urgent event notifications and delivery status alerts.

8. Add billing flow.
   Deliverable: Stripe payment links and payment tracking.

9. Add contract workflow.
   Deliverable: proposal and signature process.

10. Stand up KPI reporting.
    Deliverable: turnaround time, exception volume, and resolution metrics.

11. Run first paid pilot.
    Deliverable: live client delivery and outcome summary.

12. Produce first case study.
    Deliverable: anonymized pilot narrative with measurable result.

13. Review day-90 metrics.
    Deliverable: revenue and delivery-readiness review.
