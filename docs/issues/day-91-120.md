# Day 91-120 Issue List

## Milestone Goal

Standardize operations and prepare the system for API or white-label expansion only where evidence supports it.

## Issues

1. Document SOPs.
   Deliverable: step-by-step workflows for ingestion, publishing, lead handoff, and pilot delivery.

2. Refactor the data model.
   Deliverable: unified schema for signals, updates, leads, submissions, and cases.

3. Define the internal API schema.
   Deliverable: endpoint definitions, payloads, and access model.

4. Build internal API endpoints.
   Deliverable: first read paths for internal tools and partner testing.

5. Define free versus paid data access.
   Deliverable: rate limits, packaging, and entitlement rules.

6. Define pricing architecture.
   Deliverable: free, gated, pilot, and beta API pricing structure.

7. Build operational QA dashboard.
   Deliverable: failure monitoring for ingestion, publishing, and lead routing.

8. Capture beta partner requirements.
   Deliverable: notes from 3-5 partner conversations.

9. Define the expansion scorecard.
   Deliverable: criteria for adding a new corridor, crisis, or persona.

10. Review day-120 decision gate.
    Deliverable: recommendation to deepen the current wedge or expand.
