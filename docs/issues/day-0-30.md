# Day 0-30 Issue List

## Milestone Goal

Launch the public OSINT hub, the first ingestion jobs, the first three updates, and the lead capture path.

## Issues

1. Define the initial wedge.
   Deliverable: one-page ICP brief with persona, crisis, pain, and conversion promise.

2. Write the message architecture.
   Deliverable: homepage copy, explainer copy, CTA copy, and tone guidelines.

3. Scaffold `apps/web`.
   Deliverable: Next.js app with routes for homepage, hub, explainer, archive, and contact.

4. Set up deployment.
   Deliverable: Vercel project, environment variable plan, and deployment checklist.

5. Create the source map.
   Deliverable: 10-20 public sources with reliability ranking, cadence, and owner.

6. Scaffold `services/ingestion`.
   Deliverable: Python package structure for fetchers, parsers, and schedulers.

7. Build collector 1.
   Deliverable: source fetch, parse, and store for the highest-value source.

8. Build collector 2.
   Deliverable: second source fetch, parse, and store.

9. Build collector 3.
   Deliverable: third source fetch, parse, and store.

10. Define shared schemas.
    Deliverable: types or models for source, signal, update, lead, and submission.

11. Stand up storage.
    Deliverable: Supabase project, schema plan, and initial migrations.

12. Schedule ingestion.
    Deliverable: GitHub Actions workflow for at least daily ingestion.

13. Publish update template.
    Deliverable: reusable weekly update format with evidence and second-order effects.

14. Publish update 1.
    Deliverable: first public update in the archive.

15. Publish update 2.
    Deliverable: second public update in the archive.

16. Publish update 3.
    Deliverable: third public update in the archive.

17. Add lead capture.
    Deliverable: embedded Tally or Typeform, CTA flow, and confirmation page.

18. Sync leads to CRM.
    Deliverable: HubSpot properties, routing, and attribution fields.

19. Install analytics.
    Deliverable: Plausible events for page views, form views, and submits.

20. Create distribution templates.
    Deliverable: LinkedIn post, X thread, and email template for each update.

21. Define editorial QA.
    Deliverable: pre-publish checklist for evidence, clarity, and unsupported claims.

22. Document day-30 review.
    Deliverable: metric review and go/no-go criteria for day 31-60.
